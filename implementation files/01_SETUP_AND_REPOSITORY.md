# Setup and Repository Implementation Guide

## Goal
Create a consistent development environment for all five team members. The team uses Windows. Prefer the same Python and Node versions across all machines.

## Tools
Install:
- Git
- Visual Studio Code
- Python 3.12
- Node.js LTS
- Docker Desktop with WSL2 backend
- MongoDB Atlas account or local MongoDB for development
- Google AI Studio API key for the selected Gemini model, if that provider is used

Official downloads:
- https://git-scm.com/downloads
- https://code.visualstudio.com/
- https://www.python.org/downloads/
- https://nodejs.org/
- https://www.docker.com/products/docker-desktop/
- https://www.mongodb.com/products/platform/atlas
- https://aistudio.google.com/

Check installations in PowerShell:
```powershell
git --version
py --version
node --version
npm --version
docker --version
```

## Create repository
```powershell
mkdir sentinelmesh-ai
cd sentinelmesh-ai
git init
mkdir backend, frontend, agents, sandbox, tests, docs, examples
```

Create a shared GitHub repository and push the initial commit. Use branches and pull requests; do not let every contributor push directly to `main`.

## Backend Python environment
From repository root:
```powershell
cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

Upgrade pip:
```powershell
python -m pip install --upgrade pip
```

Create `backend/requirements.txt` with the dependencies actually used by the implementation. Initial candidate list:
```text
fastapi
uvicorn[standard]
pydantic
pydantic-settings
python-dotenv
pymongo
langgraph
langchain
langchain-google-genai
pytest
httpx
```

Install:
```powershell
pip install -r requirements.txt
```

Do not add dependencies just because they appear in this list. Pin tested versions before final submission.

## Frontend
From repository root:
```powershell
npm create vite@latest frontend -- --template react-ts
cd frontend
npm install
npm install axios react-router-dom lucide-react
```

Use the styling system already generated by Stitch/Antigravity. Do not install or replace styling libraries unnecessarily.

## Environment variables
Create a local `backend/.env` file. Example:
```env
APP_NAME=SentinelMesh AI
DEBUG=true
GOOGLE_API_KEY=replace_with_local_key
MONGODB_URI=replace_with_connection_string
DATABASE_NAME=sentinelmesh_db
FRONTEND_URL=http://localhost:5173
```

Create `.env.example` with placeholders only. Never commit `.env`, real API keys, or database credentials.

Suggested `.gitignore`:
```gitignore
.env
.env.*
!.env.example
.venv/
__pycache__/
*.pyc
.pytest_cache/
node_modules/
dist/
coverage/
```

## Git workflow
Each contributor:
1. Pull latest `main`.
2. Create a feature branch, e.g. `feature/incident-api`.
3. Make a small, focused change.
4. Run relevant tests/build.
5. Commit and push.
6. Open a pull request.
7. Ask a lead to review before merging.

Suggested branches:
- `feature/backend-api`
- `feature/ai-agents`
- `feature/frontend`
- `feature/demo-tests`
- `feature/database-audit`

## First smoke test
Create `backend/app/main.py`:
```python
from fastapi import FastAPI

app = FastAPI(title="SentinelMesh AI", version="0.1.0")

@app.get("/")
def home():
    return {"project": "SentinelMesh AI", "status": "running"}

@app.get("/health")
def health():
    return {"status": "healthy"}
```

Create `backend/app/__init__.py`, then run from `backend/`:
```powershell
uvicorn app.main:app --reload
```

Check:
- http://127.0.0.1:8000
- http://127.0.0.1:8000/docs
